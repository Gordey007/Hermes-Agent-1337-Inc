# 11 — Infrastructure

## docker-compose.yml (`infra/docker-compose.yml`)
The base VPS infrastructure:
- **minio** — S3 storage. Ports `127.0.0.1:9000` (API) and `127.0.0.1:9001` (console) — local only. Volume `hab_minio_data`.
- **minio-init** — one-time creation of the `hermes-artifacts` and `hermes-reports` buckets, `anonymous set none` (outward — only via presigned).
- Network `hab_infra_net`.

Launch: `docker compose -f infra/docker-compose.yml up -d`.
Credentials: `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` (env, defaults set in compose).

## Sprint sandboxes
Each sprint comes up in its own project: `docker compose -p hab_<tweetid>_s<sprint> -f infra/compose/hab_<tweetid>_s<sprint>.yml up -d`. The config is generated by the `developer` (`dv-scaffold`) from the template `03_auto_research/docker-compose.tmpl.yml`.
- Containers: `hab_<tweetid>_s<sprint>_<component>`.
- **No public ports outward** — full isolation of the attempt.
- Teardown: `docker compose -p hab_<tweetid>_s<sprint> down -v` (`ev-cleanup`).

## MinIO buckets
| Bucket | Contents | Outward access |
|---|---|---|
| `hermes-artifacts` | products (`hab_<tweetid>/v<outer>/<file>`) | presigned, after payment, short TTL |
| `hermes-reports` | evaluator reports (`hab_<tweetid>/s<sprint>.md`) | internal (L0 monitoring) |

## Temporary outward access
Only a presigned URL with a TTL + an OpenShell policy. Permanent keys/ports are not published outward.

## naming.py
`infra/naming.py` — the single generator of all names (see `docs/01_naming.md`). All skills/scripts call its functions.
